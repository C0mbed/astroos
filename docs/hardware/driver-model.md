# Hardware Driver Model

## Abstract Device Interface

Every hardware category is defined by an abstract interface. Drivers implement this interface. The sequencer and pipeline only talk to the interface — never to a specific driver.

### Mount Interface

```python
class AbstractMount:
    def connect(self) -> None: ...
    def disconnect(self) -> None: ...
    def slew_to_ra_dec(self, ra_deg: float, dec_deg: float) -> None: ...
    def slew_to_alt_az(self, alt_deg: float, az_deg: float) -> None: ...
    def sync(self, ra_deg: float, dec_deg: float) -> None: ...
    def park(self) -> None: ...
    def unpark(self) -> None: ...
    def abort(self) -> None: ...
    def get_ra_dec(self) -> tuple[float, float]: ...
    def get_alt_az(self) -> tuple[float, float]: ...
    def is_tracking(self) -> bool: ...
    def set_tracking(self, enabled: bool, rate: TrackingRate = TrackingRate.SIDEREAL) -> None: ...
    def is_slewing(self) -> bool: ...
    def is_parked(self) -> bool: ...
    def get_side_of_pier(self) -> PierSide: ...
```

### Camera Interface

```python
class AbstractCamera:
    def connect(self) -> None: ...
    def disconnect(self) -> None: ...
    def expose(self, duration_s: float, frame_type: FrameType) -> np.ndarray: ...
    def abort_exposure(self) -> None: ...
    def get_temperature(self) -> float: ...
    def set_temperature(self, target_c: float) -> None: ...
    def get_gain(self) -> int: ...
    def set_gain(self, gain: int) -> None: ...
    def get_binning(self) -> tuple[int, int]: ...
    def set_binning(self, x: int, y: int) -> None: ...
    def get_image_size(self) -> tuple[int, int]: ...
    def get_pixel_size_micron(self) -> float: ...
```

### Focuser Interface

```python
class AbstractFocuser:
    def connect(self) -> None: ...
    def disconnect(self) -> None: ...
    def get_position(self) -> int: ...
    def move_to(self, position: int) -> None: ...
    def move_by(self, steps: int) -> None: ...
    def halt(self) -> None: ...
    def is_moving(self) -> bool: ...
    def get_max_position(self) -> int: ...
    def get_temperature(self) -> float | None: ...
    def get_step_size_micron(self) -> float | None: ...
```

## Plugin Registration

Drivers register themselves with the plugin registry using entry points:

```toml
# pyproject.toml
[project.entry-points."astroos.drivers.mount"]
celestron_nexstar = "astroos_celestron:CelestronNexStarMount"
indi_mount = "astroos_indi:INDIMount"

[project.entry-points."astroos.drivers.camera"]
zwo_asi = "astroos_zwo:ZWOCamera"
qhy = "astroos_qhy:QHYCamera"
indi_camera = "astroos_indi:INDICamera"
```

## Device Connection Config

```yaml
hardware:
  mount:
    driver: indi_mount
    config:
      indi_server: localhost:7624
      device_name: "EQ6-R Pro"
  camera:
    driver: zwo_asi
    config:
      usb_index: 0
  focuser:
    driver: indi_focuser
    config:
      indi_server: localhost:7624
      device_name: "Moonlite Focuser"
  filter_wheel:
    driver: indi_filter_wheel
    config:
      indi_server: localhost:7624
      device_name: "ZWO EFW"
      filters: [L, R, G, B, Ha, OIII, SII]
```
